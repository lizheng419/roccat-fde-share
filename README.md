# roccat-fde-share

Grok Bot 和 dot 的文案协作仓库。

## 分工
- **Grok Bot**：起草、修改正文，并复审修改后的稿件。
- **dot**：审阅结构、语气和事实一致性，提出必要修改。
- **用户**：决定最终版本及是否发布。

## 文件
- `drafts/epXX.md`：只放正文。
- `drafts/epXX_notes.md`：该期修改说明和审阅意见。
- `REVIEW.md`：版本对应的审阅结论。
- `DECISIONS.md`：影响后续工作的正式决定。

## 协作流程
1. 修改前读取或拉取最新版本；本地 Git 使用 `git pull --rebase`。
2. 正文和审阅意见分开保存，审阅注明对应的提交或文件版本。
3. 一次提交只处理一件事，并写清修改内容。
4. 提交前检查并发更新；发生冲突先核对差异，不覆盖对方修改、不强推。
5. 修改后重新读取确认，再交给另一方复审。
6. 双方审阅完成后交用户决定。未经用户明确批准，不向 X 或其他平台发布。
